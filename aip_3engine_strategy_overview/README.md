# AIP X DeepSearch Indicator · 5-menu console

정적 파일 기반의 신규 5개 대메뉴 콘솔입니다. `index.html`을 열거나, 로컬 정적 서버에서 실행할 수 있습니다.

1. 전략 개요 — 성과 수치 없이 전략·3엔진·정량/Adjustment/AI 역할을 소개합니다.
2. 정량 분석 — 5개 분류, 세부 지표, 스코어링 범위 및 일별 종합 점수를 확인합니다.
3. Adjustment — 분류별 조정 입력, 이동 평균 기간, 구조·이벤트 확인, 스트레스와 AI 관찰 입력을 제공합니다.
4. 포트폴리오 — 유니버스, 투자 유니버스, MP 목표 포트폴리오를 페이지 내 탭으로 구분합니다.
5. 성과 분석 — 일별 실행 원장 기준의 정량 스코어 및 MP 기준 성과를 표시합니다.

`Adjustment`의 저장 값은 이 신규 콘솔 전용 로컬 브라우저 저장소에 보관되며, 원본 데이터 파일을 수정하지 않습니다.

성과 지표는 기존 일별 실행 원장 데이터(`data.js`, `etf-data.js`)를 표시하며, 월말·격주 실행 모드도 일별 포트폴리오 가치 기준으로 계산된 기존 원장을 사용합니다.
