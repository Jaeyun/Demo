DeepSearch AI 접속 가이드

ai.deepsearch.com  |  로그인부터 팀 구성원 초대까지

안녕하세요, 딥서치입니다.
DeepSearch AI 접속 방법을 단계별로 안내드립니다. 아래 순서대로 진행하시면 1~2분 안에 접속하실 수 있습니다.

1. 접속하기

  1. 브라우저(크롬 권장) 주소창에 ai.deepsearch.com 을 입력해 접속합니다.
  2. 화면 오른쪽 위의 시작하기 버튼을 클릭합니다.

ai.deepsearch.com 첫 화면 — 오른쪽 위 [시작하기] 버튼(빨간 표시)을 클릭하세요.

2. 로그인하기 (비밀번호 없음)

DeepSearch AI는 별도의 비밀번호가 없습니다. "딥서치 AI 시작하기" 화면에서 두 가지 방법 중 편한 것을 선택하세요.

① Google로 계속하기 — 회사 이메일을 Google Workspace(구글)로 사용하시는 경우. 클릭 후 회사 구글 계정만 선택하면 바로 완료됩니다.
② 이메일로 계속하기 — 그 외 모든 경우. 이메일로 받은 인증 코드를 입력합니다.

로그인 방법 선택 화면

⚠ 개인 이메일(gmail, naver 등)로는 가입할 수 없습니다. 반드시 사전 승인된 회사(업무용) 이메일을 사용해 주세요.

[이메일로 계속하기] 선택 시

  1. 업무용 이메일 주소 입력 → 인증 코드 보내기 클릭
  2. 입력한 이메일 수신함에서 딥서치가 보낸 6자리 인증 코드 확인
  3. 화면에 6자리 코드 입력 → 다음 클릭

이메일 입력 화면

인증 코드 입력 화면 — 유효시간 5분, [코드 재전송] 가능

· 인증 코드 유효시간은 5분입니다. 시간이 지나면 [코드 재전송]을 눌러 새 코드를 받으세요.

· 메일이 보이지 않으면 스팸함을 확인해 주세요.

인증이 완료되면 바로 DeepSearch AI 메인 화면(질문 입력 화면)으로 이동합니다. 다음부터 접속할 때도 같은 방식으로 로그인하시면 되고, 이미 가입된 계정은 인증 즉시 바로 로그인됩니다.

3. 팀 구성원 초대하기 (관리자)

관리자 권한이 있는 계정은 팀원을 직접 초대할 수 있습니다.

  1. 화면 왼쪽 아래 프로필 아이콘 클릭 → [설정] 선택
  2. 왼쪽 메뉴의 [관리자 모드] 클릭
  3. 왼쪽 메뉴에서 [멤버] 클릭
  4. 오른쪽 위 파란색 멤버 초대 버튼 클릭
  5. 초대할 팀원의 회사 이메일 주소를 입력하고 Enter (여러 명 연속 추가 가능)
  6. 역할(멤버/관리자) 확인 → 초대 보내기 클릭

초대받은 팀원은 안내 메일을 받은 뒤, 위 2번 로그인 절차(회사 이메일 인증)만 거치면 바로 팀에 합류되어 팀 크레딧으로 이용할 수 있습니다.
초대 진행 상황은 멤버 화면의 [초대됨] 탭에서, 멤버별 사용량도 같은 화면에서 확인할 수 있습니다.

4. 접속이 안 될 때

증상해결 방법
인증 메일이 오지 않아요스팸함 확인 → [코드 재전송] 클릭 → 그래도 안 오면 아래 연락처로 문의해 주세요.
"개인 이메일은 사용할 수 없어요"라고 나와요gmail, naver 등 개인 메일 대신 회사 이메일로 다시 시도해 주세요.
회사 이메일인데 가입이 안 돼요사전 승인된 도메인인지 확인이 필요합니다. 아래 연락처로 문의해 주세요.
로그인은 됐는데 팀 크레딧이 안 보여요사내 관리자에게 멤버 초대를 요청해 주세요 (3번 절차 참고).

이용 중 궁금한 점은 화면 오른쪽 아래 채팅 버튼으로 문의 주시면 빠르게 답변드립니다.
